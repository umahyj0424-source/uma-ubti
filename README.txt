우마무스메 취향 매칭 테스트 v0.4

실행
- ZIP 압축을 풀고 index.html을 브라우저에서 엽니다.
- 정적 HTML/JS/CSS만 사용하므로 GitHub Pages / Netlify에 그대로 업로드할 수 있습니다.

v0.4 핵심 변경
1) 매칭 알고리즘 교체
- 기존: 사용자 선호를 0~4 목표점수로 만든 뒤 142명과 RMS 거리 비교
- 문제: 여러 문항의 응답이 평균되면서 2점 부근으로 모이고, 2~3점이 많은 '무난형' 캐릭터가 반복적으로 상위권에 뜨는 현상이 큼
- 신규: 방향 선호 + 목표 수치 하이브리드
  * 어느 방향을 좋아하는지(-1~+1)를 먼저 계산
  * 캐릭터가 142명 중 해당 방향에서 얼마나 뚜렷한지 percentile(상대순위)로 평가
  * 기존 목표 수치 거리도 함께 반영
  * 기본값: 방향 선호 55% / 목표 수치 45%

2) 기본 가중치 변경
- 강한 선호 TOP 6축
- TOP 축 배수 1.7
- 중립축 최소 가중치 0.05
- 선호 강도 곡선 1.35

3) 문항 교차효과 정리
- 분석성=낮은 충동성, 배려성=낮은 독립성처럼 서로 다른 성향을 억지로 반대축으로 묶던 보조 가중치를 제거
- 15개 축마다 3문항이 해당 축을 직접 측정하도록 정리
- 노력성과 천재성도 동시에 높을 수 있도록 문항 구조 수정

4) Personality Database MBTI 보조 검증
- PDB의 우마무스메 카테고리에서 검색 가능한 커뮤니티 투표 MBTI를 일부 캐릭터의 보조 참고값으로 저장
- MBTI는 공식 설정이 아니므로 매칭 점수에 직접 넣지 않음
- 성격축과 명백하게 충돌하던 일부 수치만 보수적으로 수정
  * 골드 쉽: 분석성 0 -> 2
  * 오르페브르: 분석성 1 -> 3
  * 뒤랑달: 분석성 2 -> 3 / 충동성 2 -> 1 / 완벽주의 2 -> 3 / 책임감 2 -> 3
  * 드림 저니: 분석성 2 -> 3
  * 홋코 타루마에: 배려성 2 -> 3 / 책임감 2 -> 3
- 데이터 조정 > 캐릭터 수치에서 확인된 PDB MBTI가 표시됨

5) 분포 진단 기능
- 데이터 조정 > 매칭 설정 > '1,200회 분포 테스트'
- 중간 응답 40%, 약한 선택 40%, 강한 선택 20%를 가정해 결과 쏠림을 즉시 확인
- 1위 등장 캐릭터 수 / 유효 다양성 / 최다 독점률 / TOP10 집중률 표시

개발 시뮬레이션 참고
- v0.3 방식, 중립 응답이 많은 10,000회 모의: 유효 다양성 약 21.8명 / 최다 1위 약 14.5% / TOP10 집중 약 74.5%
- v0.4 기본값, 같은 조건 10,000회 모의: 유효 다양성 약 97.4명 / 최다 1위 약 3.6% / TOP10 집중 약 26.0% / 141명이 최소 1회 이상 1위 등장
- 이 수치는 실제 사용자 분포가 아니라 알고리즘 쏠림 확인용 모의값입니다.

주의
- 새 버전은 localStorage 키를 V04로 변경했습니다. 예전 V0.3 브라우저 설정이 새 기본값을 덮어쓰지 않습니다.
- Personality Database 결과는 사용자 투표 기반 참고자료이며 공식 MBTI가 아닙니다.

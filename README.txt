우마무스메 취향 매칭 테스트 v0.1

구성
- index.html : 메인 사이트
- assets/js/data.js : 142명 × 15축 데이터
- assets/js/questions.js : 45문항과 문항별 가중치
- assets/js/app.js : 테스트/매칭/관리자 기능
- data/character_traits.csv : 제작 기준 원본 CSV

실행
1. 압축을 풉니다.
2. index.html을 브라우저에서 열면 로컬에서도 동작합니다.
3. GitHub Pages / Netlify에 폴더 그대로 업로드할 수 있습니다.

테스트 계산
- 각 문항은 1~5 선택입니다. 1=-1, 3=0, 5=+1 방향으로 변환합니다.
- 문항마다 weight와 effects(축별 영향값)가 있습니다.
- 45문항 응답을 15축의 0~4 선호 벡터로 변환합니다.
- 사용자 선호 벡터와 142명 캐릭터 벡터의 가중 RMS 거리를 계산해 순위를 냅니다.
- 캐릭터별 기존 확신도는 거리 계산에서 약한 보정(0.75~1.0)으로만 반영합니다.

데이터 조정 탭
- 캐릭터 수치: 캐릭터를 선택해 15축을 0~4 슬라이더로 수정하고 저장합니다.
  직접 수정한 축은 확신도를 1.0으로 처리합니다.
- 문항/가중치: 문항 텍스트, 좌우 선택지, 문항 전체 weight, 15축별 effect를 수정합니다.
- 가져오기/내보내기:
  · 전체 JSON: 캐릭터+문항을 통째로 백업/복원
  · 캐릭터 CSV: 142명 15축 점수를 엑셀 등에서 수정 후 다시 가져오기
- 수정값은 브라우저 localStorage에 남습니다.

현재 UI 명칭
- 기존 데이터의 '이성성'은 사용자에게 더 직관적으로 보이도록 '분석성'으로 표시합니다.
- 기존 '역경성'은 성격이 아니라 서사 지표이므로 '역경 서사'로 표시합니다.

다음 개선 후보

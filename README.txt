우마무스메 취향 매칭 테스트 v0.3

실행:
- index.html을 브라우저에서 열거나 폴더 전체를 GitHub Pages / Netlify에 배포합니다.

v0.3 변경사항:
- 모바일(560px 이하): 45문항 전체 나열 대신 한 문제씩 표시
- 모바일: 선택 후 약 0.22초 뒤 자동으로 다음 문제 이동
- 모바일: 이전/다음 질문 버튼으로 자유롭게 재검토 가능
- 선택 척도: 1 / 2 / 중간 / 4 / 5 숫자 대신 ◀◀ / ◀ / ● / ▶ / ▶▶ 방향형 UI
- 좌/우 선택지에 A / B 표시 추가
- 결과 보기 고정 바는 모바일에서 모든 문항 완료 전까지 숨김
- 완료 후 결과 보기 버튼은 일반 영역으로 표시되어 화면을 가리지 않음
- v0.2의 결과 막대 범례 및 강한 선호축 가중 알고리즘 유지

관리자 기능:
- 캐릭터 15축 수치 수정
- 문항/가중치 수정
- 매칭 가중치 설정
- JSON/CSV 가져오기 및 내보내기
